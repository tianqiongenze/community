# 器识开源社区 · QISHI Open Community

> 「先器识，而后文艺」——判断与担当在技法之前。
> Judgment before craft. This community builds the engineering behind machines that listen, classrooms that scale, and fields that get measured.

这里是**器识开源社区**的中心仓库：议题板、角色阶梯、公开路线与致谢区都在这里。代码在各具体仓库，**「该做什么、缺什么人」在这里**。

站点：<https://frontier-open-community-ycd67ymg7cr.qoder.website>（实时仓库清单、技术雷达、可认领议题）

## 我现在就能做的三件事

1. **认领一个议题** → [`good first issue` 标签](https://github.com/tianqiongenze/community/labels/good%20first%20issue)。每个都写明具名兜底人和验收标准，7 天内给你第一次完整评审。
2. **报一个真实场景的问题** → 新开议题，写清「场景 / 已有数据 / 期望产出」。多数仓库还没有议题，你的第一条就会成为口径。
3. **提一条轨道提案** → 标题带 `【轨道提案】`。具身智能与智慧农业农村两条轨道**当前名下没有自有仓库**，首位认真提案并落地的人就是这条轨道的初始维护者。

## 四条研究轨道

| 轨道 | 现状 | 在做什么 | 缺什么人 |
| --- | --- | --- | --- |
| 工业互联网 Industrial IoT & Agent Ops | 活跃，持续提交 | 用 Agent Harness 把 ISO 13374 六功能块（DA→DM→SD→HA→PA→AG）工程贯通，交付可审计、可降级、可回滚的维护决策系统 | 边缘协议工程师、时序特征工程、智能体评测 |
| AI 教育与职教数字化 AI Curriculum Infrastructure | 资产最厚，双平台同步 | 四门课程的「七件套」教学资产（课程标准/授课计划/教学设计/任务单/PPT/代码/微课），以及承载它的教学平台 | 课程共建教师、教学平台开发、实训环境维护 |
| 具身智能 Embodied Intelligence | 筹备中，名下尚无仓库 | 把已验证的 harness 交给巡检载体与机械臂；先仿真台架与可复现评测，再上真机 | ROS/控制栈、仿真与评测、感知模型落地 |
| 智慧农业农村 Smart Agriculture & Rural | 筹备中，名下尚无仓库 | 把工业级遥测方法下沉到农机、灌区与县域治理，用领域知识图谱承担农艺推理 | 农艺领域专家、边缘采集、县域合作对接 |

底座（工程沉淀）：幂等防重组件、IKExpression 优化、脑图汇总，以及 `xopencode` 组织下使用最广的 BistouryX 生产诊断工具。

## 语言

课程与工业仓库以中文为主，因为它们真实服务于中文职教课堂与产线现场。**不要机翻它们**；需要英文时，另写英文概览并链接回原文。本仓库与站点提供 zh / zh-Hant / en 三语界面。
